# Meng Lab Website (Modern Biomedical / AI Bioinformatics Style)

This is a GitHub Pages-ready static website template.

## Files
- `index.html`
- `style.css`
- `assets/`

## How to use
1. Create a GitHub repository named `yourusername.github.io`
2. Upload all files from this folder to the repository root
3. Commit the files
4. Enable GitHub Pages if needed in repository settings

## Update before publishing
- Add your final institution, department, and email
- Replace placeholder publication entries with full citations and links
- Replace placeholder lab image
- Add your real GitHub / Google Scholar / profile links
